## 建议

1. 在 Seller Central 确认当前连接的卖家账号是否就是预期经营账号，并对照最近 30 天的订单数。
2. 确认商品使用 FBA 还是 FBM。若为 FBM，当前 FBA 库存接口返回空属于正常现象。
3. 在新增 Amazon API 权限前，先以 Seller Central 核对活动 Listing 数、履约方式和可售数量。
4. 如需要 MCP 自动诊断“有 Listing 但无订单”，下一优先级是接入只读 Listings/Offers 状态和 FBM 库存，不建议直接开放改价或 Listing 写操作。
5. 等出现非零订单和库存后，再建立每日体检基线，持续跟踪订单、履约异常和库存风险。

## 数据边界

本报告仅使用订单、FBA 库存、Sellers 和连接健康的只读数据，不包含买家、收件人、地址、支付授权、追踪号或凭证信息。本次报告没有采集 Listings Items；当前 MCP 后续版本虽已提供 feature-gated Listings 只读抽样，但仍不覆盖 FBM 全渠道精确库存、广告、退款、退货、结算和净利润数据。
